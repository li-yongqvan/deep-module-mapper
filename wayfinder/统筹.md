## 3. 给临时统筹方的操作说明（协议）

被召唤时照做（执行细节见 `temporary-coordinator` skill），做完即"下班"：

> **提示**：`temporary-coordinator` 是项目级 skill，只在从 `deep-module-mapper/` 目录开会话时自动加载。若本会话从 `agent panel/` 根（或别处）打开、skill 未被识别，直接按下面协议执行即可——协议本体就在本文件，不依赖 skill。

1. 读本文件 + `wayfinder/map.md`（当前状态）。
2. 逐份处理「待处理」报告：核实 → 更新 map.md（完成的票移入 Decisions / 决策落档 / Open frontier 变更）→ 同步 GitHub issue #1 镜像 → 需要时写下一票 handoff/设计文档。
3. 报告从「待处理」移到「已处理」，附一行结论 + 日期。
4. 在「处理日志」加一行。
5. 向用户汇报摘要。
6. 明确自己是临时统筹方，处理完即止。

**红线**：临时统筹方只做协调，不实现 ticket、不擅自扩大范围、不替用户拍板未定决策。
